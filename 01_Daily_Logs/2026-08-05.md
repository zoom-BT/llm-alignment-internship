## Concepts Covered Today (In English)
### Prompt Masking, Padding, and Sequence Structure
- **Masking the Loss on Prompt Tokens:** the model shouldn't be rewarded or penalized for "predicting" the instruction itself (it didn't generate that, the user wrote it) — only the response tokens contribute to the loss, via `-100` labels on everything else (PyTorch's cross-entropy ignores that index).
- **Padding and Truncation:** padding (seen in Wednesday of Week 1, with left-padding for batched generation) fills shorter sequences up to a common length; truncation cuts sequences that exceed `max_seq_length` (`512` in `config.yaml`) — both needed to fit variable-length examples into fixed-shape batches.
- **Sequence Packing & Maximum Context Length:** packing concatenates several short examples into one training sequence to reduce wasted padding; `max_position_embeddings: 32768` in Qwen2.5-0.5B's `config.json` sets the hard ceiling on how long a single sequence can be.
