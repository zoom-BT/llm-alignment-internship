## Concepts Covered Today (In English)
### A Comparison Arm Is What Separates Research From Engineering
- **"Aligning a base model improves it" has been known since InstructGPT in 2022.** A paper reporting that would be told so by its first reviewer. The novelty cannot live in the act, only in the comparison — hence arm A2, the same recipe on the original base.
- **The data wall of v1 does not apply here.** H1 needed the data to *have a property* (natively rather than machine translated), and no source had it. This design needs only that both arms receive *the same* data: their flaws strike A2 and A3 identically and cancel in the difference. Imperfect data limits what can be said about the absolute level, not about the gap.
- **A shared tokenizer is a stronger control than expected.** Both backbones report the same 248,044-token vocabulary, so no measured difference can be attributed to one segmenting African text more efficiently. This also retracted an earlier claim that AfriqueQwen had *extended* the vocabulary — it inherited it.

### Verifying Research Reports Rather Than Consuming Them
- **Confidence ratings were inverted.** Of two external dataset reports, the entry marked "High confidence, explicitly documented" turned out to be gated and unverifiable, while two marked "Moderate, inferred" were real and usable.
- **Six false claims, found by querying the source.** Bactrian-X was credited with 8,435 Hausa examples and has no Hausa config at all; AfriSpeech-Dialog was classified as African-language data and is African-accented *English*; three licences were inferred rather than read, and two of those datasets declare none.
- **One correction went the other way.** Aya was reported at 1,200-1,500 Hausa examples; direct measurement gives **3,512**, natively authored and Apache-2.0 — the best source found since the project began.

### Failing Fast Is Worth Building Before You Need It
- **A Kaggle secret cannot be attached through the API**, and an API push appears to clear attachments made in the editor. Two real runs established this. Without a fail-fast guard, a submitted notebook would have installed packages, downloaded 9 GB of weights, and only then failed — GPU quota spent on a configuration error.
- **The workaround removed the dependency rather than working around it.** Shipping the code as a private Kaggle Dataset drops the git clone, the token, and the manual editor step all at once. `dataset_sources` is a real metadata field the API honours.
- **Checking a command should never cost what the command costs.** Verifying the submission previously required submitting it, which publishes and spends quota. A `--dry-run` now builds and prints without sending.
