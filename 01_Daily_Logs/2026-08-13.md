## Concepts Covered Today (In English)
### AI Feedback and the Parameter-Efficiency Spectrum
- **RLAIF vs. RLHF:** same pipeline shape (preferences → reward signal → optimization), except the preference judgments come from another language model instead of a paid human labeler — much cheaper and faster to scale, but inherits whatever blind spots that judge model has.
- **Constitutional AI:** instead of collecting human preferences directly, the model is given a written set of principles, asked to critique its own output against them, then revise — preference data is *generated*, not collected from people.
- **The parameter-efficiency spectrum, one line each:** full fine-tuning (every weight updates, most expressive, most memory); adapters (small trainable modules inserted into a frozen model); prefix/prompt tuning (only a continuous prompt vector is learned, model itself stays frozen); LoRA (learns a low-rank *update* to selected weight matrices, frozen base); QLoRA (LoRA, but the frozen base is stored in 4-bit — same trainable parameters, far less memory to hold the base model).
