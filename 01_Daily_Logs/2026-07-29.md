## Concepts Covered Today (In English)
### Autoregressive Generation & Baseline Metrics
- **Autoregressive Decoding:** Generating text token by token where each new token is conditioned on all previously generated tokens.
- **Sampling Parameters:** - `temperature`: Controls randomness in output distributions.
  - `top_p` (Nucleus sampling): Limits token selection to a cumulative probability threshold.
- **Perplexity & Benchmark Metrics:** Quantifying model uncertainty and output quality prior to fine-tuning.
