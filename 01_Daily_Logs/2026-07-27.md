##  Concepts Covered Today (In English)
### VRAM & Precision Types
- **FP32:** 4 bytes per parameter.
- **FP16 / BF16:** 2 bytes per parameter. Reduces memory overhead by ~50%.

### Deep-Dive Recap: From Infrastructure to First Principles

Today wasn't just about scaffolding a repository — I went back through everything I'd been using without really understanding it, and it paid off.

**Git** stopped being "the thing that saves my code" and became a proper mental model: working directory → staging area → commit history, with `push` as the only step that actually leaves my machine. Small, single-purpose commits aren't a style preference — they're what makes `git log` useful for debugging later.

**Reproducibility** turned out to be a literal contract obligation (Article 7.6), not just good practice. `set_seed()` has to touch `random`, `numpy`, and `torch` separately because each has its own independent random number generator — and even then, reproducibility across different GPUs/library versions isn't guaranteed, which is why documenting software versions matters just as much as the seed itself.

**Tensors**, seen for real: a tensor is a flat, contiguous block of memory plus shape/dtype metadata — nothing more mystical than that. Timed it myself: a pure Python loop over 2M multiplications took 0.36s; the same operation vectorized in NumPy/PyTorch took ~0.01s — a 30-40x speedup from SIMD instructions operating on contiguous memory instead of looping element-by-element. That's the same mechanism that makes GPU training possible at scale, just with thousands of cores instead of a handful.

**FP32/FP16/BF16** finally clicked as a *role* split, not just "smaller = better": exponent bits control range (over/underflow risk), mantissa bits control precision (whether tiny gradient updates survive accumulation). BF16 keeps FP32's range but sacrifices precision — exactly why it's the safer default for training without needing loss-scaling tricks.

**Subword tokenization**, tested live on Qwen2.5-0.5B: "the" stays a single token, but "Afrique" gets split into "Af" + "rique" — a small, concrete reminder that this model's 151k-token vocabulary wasn't built with French/African-language text as a priority. Worth keeping in mind for the actual research direction later in the internship.
